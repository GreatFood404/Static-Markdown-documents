## 不锈钢刀挑选参考
**不锈钢刀选择主要选择钢材，钢材越好刀的耐用性锋利度高**  
*例：40Cr13 MoV*

| 元素 | 用处 |
| :---: | :--- |
| 40 | 碳含量0.4% |
| [Cr铬](https://wuu.wikipedia.org/wiki/%E9%93%AC "跳转至维基百科详解") | 铬元素，铬含量越高不锈钢越防锈 |
| 13 | 铬含量13% |
| [Mo钼](https://wuu.wikipedia.org/wiki/%E9%92%BC "跳转至维基百科详解") | 钼元素，提高不锈钢抗腐蚀能力 |
| [V钒](https://wuu.wikipedia.org/wiki/%E9%92%92 "跳转至维基百科详解") | 钒元素，提高不锈钢硬度 |

> **备注**  
> 碳含量越高，刀越硬，铬含量越高，刀越防锈。  
> 钼与钒对不锈钢抗腐蚀性与硬度提升有限，预算充足可选
